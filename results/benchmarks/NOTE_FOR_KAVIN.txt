NOTE FOR KAVIN -- JNE-110355 honest benchmark re-run (2026-05-28, g2-standard-8, L4 GPU)

All three JAX scenarios were measured at the full 600 ms biological time (24000 steps @ dt=0.025 ms), 450 neurons (100 STN / 200 GPe / 150 GPi), seed=42, using the published BENCH_PARAMS. None were extrapolated. Wall-clock medians: JAX GPU (JIT+scan) = 1.424 s; JAX CPU (JIT+scan) = 3.180 s; JAX GPU (no-jit Python loop) = 1047.086 s. Honest same-model ratios: JIT + kernel-fusion speedup (no-jit / JIT, both on the L4 GPU, both HH+RT) = 736x; GPU-vs-CPU speedup for the compiled model (CPU-JIT / GPU-JIT) = 2.2x. The NumPy/AdEx baseline ran the standalone numpy_baseline integrator at the same 450-neuron sizing for the full 600 ms, wall clock 57.97 s end-to-end (54.54 s in the integration loop per manifest.json), single-threaded ~102% CPU on the 8-vCPU node; this uses AdEx for GPe/GPi and a light-HH formulation for STN -- a different model from the JAX HH+RT path -- so it is reported as a reference point only and explicitly NOT a comparable speedup baseline. Raw data: results/benchmarks/honest_benchmark.json (JAX runs), results/benchmarks/numpy_adex_timing.txt (NumPy/AdEx run), results/benchmarks/HONEST_SUMMARY.txt (per-scenario table + the two honest ratios). Script: scripts/benchmark_honest.py. No commits made; rebuild branch and bgnet package untouched.
